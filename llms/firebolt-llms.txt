# Firebolt Documentation

> Firebolt is a high-performance cloud data warehouse optimized for sub-second analytics at scale. This documentation covers SQL references, architecture, integrations, security, and operational guides for developers and data engineers.

## Docs

- [What is Firebolt?](https://docs.firebolt.io/overview.md): Firebolt is a high-performance, open source analytical database. It runs as a single binary on a laptop and scales to hundreds of nodes and petabytes of data on object storage in your own cloud.
